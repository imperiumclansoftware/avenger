Essayer le widget ↗

1. Le code minimal

Collez cette ligne dans les pages de votre application, juste avant </body> :

Le bouton apparaît en bas à droite. Avenger n'est contacté qu'à l'ouverture du formulaire.

2. Pré-remplir l'utilisateur connecté

Si votre application connaît l'utilisateur, transmettez son nom et son e-mail : il n'aura pas à les saisir. Ils ne passent pas par l'adresse de l'iframe, seulement par un message réservé à Avenger.

3. Utiliser votre propre bouton

Avec data-button="false", le bouton flottant disparaît : ouvrez le formulaire depuis un menu ou un lien de votre application.

4. Dans une application Angular

Un service qui charge le script au premier clic, puis ouvre le formulaire avec l'utilisateur connecté :

Options

AttributValeurRôle
data-product{{ product.slug }}Obligatoire : le produit qui reçoit les tickets
data-typebug, feedback, featureFile proposée par défaut (bug sinon)
data-labeltexteTexte du bouton et titre de la fenêtre (« Signaler un problème »)
data-positionbottom-right, bottom-leftCoin du bouton flottant
data-buttonfalsePas de bouton flottant : ouverture par AvengerTickets.open()
data-name, data-emailtextePré-remplissage de l'auteur, pour une page générée côté serveur
data-page-urlfalseNe pas joindre au ticket l'adresse de la page (sans paramètres ni fragment)

API JavaScript

MéthodeRôle
AvengerTickets.open({ type, name, email })Ouvre le formulaire ; les options sont facultatives
AvengerTickets.set({ type, name, email })Change le pré-remplissage, par exemple après la connexion
AvengerTickets.close()Ferme le formulaire

Après chaque envoi, la page reçoit l'événement avenger:ticket-created :

Sécurité

  • Le formulaire est servi par Avenger dans un iframe isolé : il n'a accès ni aux données ni aux cookies de votre application, et ne peut pas la rediriger.
  • Les deux côtés n'acceptent que les messages de la fenêtre et de l'origine attendues ; l'e-mail de l'utilisateur n'apparaît dans aucune adresse.
  • L'envoi est limité à 10 tickets par quart d'heure et par adresse IP, comme sur le site public.

Si votre application impose une politique de sécurité du contenu (CSP), autorisez Avenger :

Côté Avenger, les pages /widget/… doivent pouvoir être affichées dans un iframe : n'ajoutez pas d'en-tête X-Frame-Options ou frame-ancestors qui l'interdirait.
